# VELT Цена величия

Новая самостоятельная редакция романа и сайт для чтения. Написана часть I «Начало»: главы 1–20, 2007–2017. Действующие лица и проза созданы заново.

Читать: https://veylcode.github.io/velt-price-of-greatness/

Фактический объём первой части — 15 595 слов. Её сюжет завершён; главы короче ориентира 2500–4500 слов из исходного задания. Это версия для просмотра, а не заявление о достижении объёма большого романа. Части II–IV пока не написаны.

## Структура

- `manuscript/01.md` — `20.md`: единственные исходники глав. `VELT-Part-I.md` собирается автоматически.
- `author/`: канон, персонажи, время, улики, план, редакторские ограничения и точный счётчик.
- `site/`: статический сайт, обложка, EPUB и TXT. Он работает без сервера приложений и внешних шрифтов.
- `tools/build.py`: сборка сайта и книг стандартной библиотекой Python 3.12+.
- `tools/check_site.cjs`: проверка чтения, настроек, навигации и доступности в браузере через Playwright.
- `work/`: локальные проверки; не публикуется в Git.

## Запуск

Из корня проекта:

```text
python tools/build.py
python -m http.server 8765 --directory site
```

Откройте `http://localhost:8765/`. Для чтения готовых страниц сборка не требуется.

## Читалка

Книжный и лаконичный стили меняют гарнитуру и расположение абзацев. Бумажная, светлая и ночная палитры доступны отдельно от стиля; автоматическая следует системной теме. Размер, интервалы, ширина строки, место и закладки хранятся только в браузере. При недоступном хранилище показывается объяснение. Передачи этих данных на сервер нет.

Текст и переходы между главами доступны без JavaScript. Диалоги закрываются Escape, удерживают клавиатурный фокус и возвращают его к открывшей кнопке. Режим без панелей имеет отдельную кнопку выхода и Escape. Уменьшенное движение учитывается.

## Публикация

GitHub Pages публикует корень отдельной ветки `gh-pages`, содержащей только `site/`. Исходники книги и инструменты находятся в `main`.

```text
git add .
git commit -m "Update VELT part one"
git push origin main
git subtree split --prefix=site -b pages-next
git push origin pages-next:gh-pages
git branch -D pages-next
```

Имя временной ветки должно быть свободно. Нельзя форсировать обновление чужой ветки. EPUB проверяется на структуру и совпадение текста с сайтом; импорт на реальном MiBook не заявлен проверенным.
